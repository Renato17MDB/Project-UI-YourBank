# 🏦 YourBank UI

## 🧠 Descrição

O **YourBank UI** é um projeto front-end que simula a interface de um banco digital moderno, com páginas responsivas e componentes visuais completos.  
O objetivo é praticar boas práticas de layout, estilo e estrutura de interface usando tecnologias web nativas.

No site você pode navegar por telas como **Home**, **Produtos de Conta**, **Transações**, e visualizar uma interface rica em informação e elementos comuns em aplicativos bancários.
---

## ⚙️ Status do Projeto

Este projeto está **em desenvolvimento**.  
Funcionalidades já implementadas incluem a interface principal, navegação básica e seções de um banco digital.  
Recursos planejados incluem validação de formulários, integração com backend e melhorias de UI/UX.

## 🛠️ Tecnologias

✔ HTML5  
✔ CSS3  
✔ JavaScript (Vanilla)  

📌 Não utiliza frameworks — ideal para reforçar fundamentos web.
